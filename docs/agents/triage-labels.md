# Triage labels

Canonical roles map 1:1 to label strings (defaults kept):

- `needs-triage` -> `needs-triage`
- `needs-info` -> `needs-info`
- `ready-for-agent` -> `ready-for-agent`
- `ready-for-human` -> `ready-for-human`
- `wontfix` -> `wontfix`

For the local markdown tracker, these appear as `Status:` values in issue files.
